# Projects

This repository contains a selection of academic projects developed during my studies in **Mathematical Engineering at Politecnico di Torino**.

The projects mainly focus on **data analysis, machine learning, reinforcement learning, numerical methods, mathematical modelling and scientific computing**.

Each project is organized in a separate folder and documents a specific academic activity or computational study.

---

## Projects

### `PCA-and-Clustering`

Academic project developed for the **Computational Linear Algebra** course.

The project applies **Principal Component Analysis (PCA)** and **unsupervised learning techniques** to a high-dimensional survey dataset containing information about interests, habits, preferences, personality traits and demographic characteristics.

The analysis includes:

- preprocessing of numerical and categorical variables;
- normalization and dimensionality reduction using PCA;
- interpretation of the principal components;
- application of **K-Means clustering** in the reduced space;
- selection of the number of clusters using the **Silhouette Score**;
- analysis and interpretation of the resulting behavioural profiles.

The final analysis identifies four different clusters and explores the relationship between the resulting groups and demographic variables.

---

### `Model-Order-Reduction-Machine-Learning`

Academic project developed during the **Model Order Reduction and Machine Learning** course.

The project focuses on the numerical solution of a **parametric two-dimensional fluid dynamics problem** and on the use of reduced-order and machine-learning techniques to obtain faster approximations of the original model.

The work includes:

- construction of a reference numerical model;
- dimensionality reduction using **Proper Orthogonal Decomposition (POD)**;
- development of a reduced-order model based on a **POD-Galerkin** approach;
- use of a **neural network** to predict reduced-order solutions;
- comparison between the full model and the reduced approaches in terms of accuracy and computational cost;
- implementation of a **Physics-Informed Neural Network (PINN)** as an alternative machine-learning approach.

The project provides a comparison between classical numerical modelling, reduced-order techniques and machine-learning-based approximations.

---

### `Faimdl_Project`

Academic project developed in the context of the **Fundamentals of Artificial Intelligence, Machine and Deep Learning** course.

The project focuses on the implementation and comparison of different **Reinforcement Learning algorithms** in simulated control and robotic environments.

The work includes:

- implementation and comparison of **REINFORCE** and **Actor-Critic** on the Hopper-v4 environment;
- analysis of training behaviour across multiple random seeds;
- comparison of reward trends and computational cost;
- training of **PPO** and **SAC** agents on the PandaPush-v3 robotic environment;
- evaluation of trained agents using return and success-rate metrics;
- application of **domain randomization** techniques to improve robustness and generalization.

The project combines algorithm implementation, experimental evaluation and comparison of different reinforcement-learning approaches.
